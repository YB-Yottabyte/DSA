# DSA

A minimal starter setup for practicing Data Structures and Algorithms.

## Structure

- `problems/` - problem statements and notes
- `solutions/python/` - Python solutions
- `tests/python/` - Python unit tests

## Getting Started

1. Pick or add a problem in `problems/`
2. Implement a solution in `solutions/python/`
3. Add/update tests in `tests/python/`
4. Run tests:

```bash
python -m unittest discover -s tests/python -p "test_*.py"
```

## Included Example

- Problem: `problems/two_sum.md`
- Solution: `solutions/python/two_sum.py`
- Test: `tests/python/test_two_sum.py`
